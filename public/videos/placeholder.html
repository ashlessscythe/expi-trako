Video Placeholders for Landing Page

This page demonstrates the video placeholders needed for the landing page. Replace these placeholders with actual screen recordings of your application.

Note: For each video, you should create both WebM and MP4 versions for maximum browser compatibility.

Required Videos

The following video files need to be created and placed in the /public/videos/ directory:

  • dashboard-demo.webm and .mp4 - Main hero section
  • real-time-tracking.webm and .mp4 - Feature section
  • analytics-demo.webm and .mp4 - Feature section
  • request-flow.webm and .mp4 - Showcase section
  • dashboard-overview.webm and .mp4 - Showcase section

Next Steps

  1. Create screen recordings of your application showing key features
  2. Convert recordings to both WebM and MP4 formats (see the video guidelines document)
  3. Name files according to the list above
  4. Place all files in the /public/videos/ directory
  5. Test the landing page to ensure videos play correctly

For detailed instructions on creating and converting videos, refer to the Video Guidelines document.
